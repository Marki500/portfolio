# Marc Iglesias Portfolio

Landing page construida con [Astro](https://astro.build/), [React](https://react.dev/) y [Tailwind CSS](https://tailwindcss.com/) para el desarrollador full-stack Marc Iglesias Simón.

## Scripts

```bash
npm install      # instala dependencias
npm run dev      # inicia servidor de desarrollo
npm run build    # genera la versión estática
npm run preview  # sirve la versión construida
```
